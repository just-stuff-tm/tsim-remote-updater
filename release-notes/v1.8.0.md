# tsim-updater 1.8.0

## One timer for automatic check-ins

Before, several settings each had their own timer: the modem watchdog, low-battery protection, the saved copy of the repeater settings, GPS and the mesh snapshot. Now there is one **Automatic check-ins** card on the T-SIM tab.

- **Check in every:** Off, or every 1, 2, 3, 6, 12 or 24 hours. Each check-in uses LTE.
- **On each check-in:** tick what the T-SIM should do: report its status, pick up queued commands, read mesh stats, refresh the saved repeater settings, get a GPS fix, run waiting texts.
- **Quick local checks (no LTE):** a short wake, about a second, that checks the battery (low-battery protection) and notices a repeater reboot. It does not turn on the modem.
- The card shows a rough daily battery cost while you change it.
- **Off really means off.** With 1.8.0, Off stops timed check-ins. The T-SIM still checks the modem once a day so it can't get stuck offline, but it only uses LTE if it had to fix something or has a report waiting. Older firmware still checked every 24 hours.
- Waking the T-SIM by text on a schedule is still there, under **Advanced: also wake by text**.

## The dashboard shows what the T-SIM actually runs

Each settings card now shows two values:

- **On T-SIM:** what the T-SIM last confirmed, and when.
- **Saved here, not confirmed yet:** shown only when your saved value is different. It has a **Waiting for T-SIM to confirm** badge until the T-SIM picks the change up.

A saved value is never shown as the T-SIM's value. A 1.8.0 T-SIM reports its full check-in settings on every report.

## Repeater settings are easier to find

The repeater settings are grouped as Identity, Location, Radio, Repeating, Adverts and Power saving. Rarely used options sit under **More options** in each group, or in one **Advanced** section (timing, bridge, diagnostics, passwords). Labels use plain words.

- **Apply changes (N)** sends your changes now with one text.
- **Apply at next check-in (no text)** queues them for the T-SIM's next check-in.

## No more duplicate commands

- The same command can't be queued twice. A newer settings change replaces an older one that is still waiting.
- A double click or a page reload can't submit the same action twice.
- The queue has a limit, with a clear message when it is full.
- If a wake text was sent in the last 15 minutes and the T-SIM hasn't answered yet, no second text is sent. Your change waits for that wake. You can still use **Send another text anyway**.
- Items not picked up within 7 days expire.
- A **Waiting to be sent** list shows everything queued, and each item has a **Remove** button.
- The 1.8.0 firmware ignores a command it has already run, and applies only the newest settings change of each kind it gets at once.

## Other fixes

- The battery card shows the newest settings the T-SIM confirmed, not an older report.
- A red "couldn't be downloaded" line no longer stays on screen after a later update succeeds.
- Low-battery protection and the saved copy of repeater settings now live on the T-SIM tab.

## Upgrading

The dashboard already works with T-SIM 1.7.x. Options that need 1.8.0 are greyed out with a note until you upgrade. To upgrade, open the T-SIM tab, press **Check**, then **Update T-SIM firmware**. Your existing settings carry over: 1.8.0 reads its first check-in settings from the old ones, and it keeps the old settings so you can roll back.
