# tsim-updater 1.8.1

## Radio flash is more patient, and the dashboard says where it stopped

A flash that switched the radio link to 460800 baud could fail before anything was erased. The radio then booted its old firmware, and the dashboard only showed "flash failed".

- If the fast link fails while starting the erase or while writing, the T-SIM puts the radio back into download mode and flashes the whole file again at 115200 baud. It tries that once.
- If the radio refuses the faster rate, the T-SIM stays at 115200 and continues. It does not switch its own UART.
- Erase is allowed about 30 seconds per megabyte, so a large image is not cut off at 12 seconds.
- The activity log now names the step (connect, baud, start, write, verify), the error, and the baud rate. The update card turns that into a short explanation and keeps the raw line under Technical detail.
- Older T-SIM firmware, which does not send those fields, still shows the same failure text as before.

## A text runs on the wake that received it

A text that woke the T-SIM was often still on its way into the modem when the inbox was read. The T-SIM then ran the previous text, and the new one waited until the next wake, which could be hours later. The "new message" notice was also easy to miss, because other modem commands clear the serial buffer.

- On a text wake the T-SIM checks the inbox every few seconds for up to about 30 seconds, until the new text has been read.
- It reads every stored text, oldest first. A text it has already run is skipped. A Retry from the dashboard is a new text, so it still runs.
- If the ring pin is still active, or a new-message notice arrives after the last check, it reads the inbox once more before sleeping.
- The T-SIM card shows how many inbox checks ran and whether a new text was found.

Install this firmware on the T-SIM (USB or T-SIM update). The radio firmware does not need to change for these fixes.
