## `tsim wake` frames, and GPIO6 is no longer a Heltec-reboot detector

The repeater command `tsim wake` (MeshCore-TSim-Powersaving) pulses Heltec TX so GPIO6 wakes the T-SIM, then sends `@TSIM <CMD> <seq>` until it sees `@TSIM ACK <seq>`.

- On a GPIO6 wake, listen 9 seconds for a frame.
- Allowlist: `WAKE` (ACK, modem stays asleep), `STATUS` (ACK, then a status report), `MODEM_RESET` (ACK, then the same modem recovery as a forced watchdog check). Anything else is logged and not ACKed.
- The same seq is ACKed again and not run twice. An echoed `@TSIM ACK` is ignored.
- Frames that arrive while the T-SIM is already awake are handled the same way.
- No `@TSIM` frame: the pulse is ignored. It does not reset the modem and it does not count as a Heltec reboot. GPIO6 stuck low still turns the wake off after repeated tries (`WDCFG hwake=1` turns it back on).

The while-awake serial check (1.7.4) and the daylight uptime check (1.7.5) are unchanged.

Install from the dashboard with **Update T-SIM firmware**. The Heltec update source for an untouched default now follows `just-stuff-tm/MeshCore-TSim-Powersaving` (`Heltec_v3_repeater-MeshCore-TSim-Powersaving*-upgrade.bin`). The previous MeshCore + power saving preset is still in the list.
