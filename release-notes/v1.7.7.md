## @TSIM frames for `tsim wake` (local, not released)

Not published and not flashed. v1.7.6 is still the release on the dashboard. This build is the local branch `tsim-wake-frames` in `/workspace/tsim-v172`.

The repeater command `tsim wake` (MeshCore-TSim-Powersaving) pulses Heltec TX so GPIO6 wakes the T-SIM, then sends `@TSIM <CMD> <seq>` on the serial link until it sees `@TSIM ACK <seq>`.

1.7.7:
- On a GPIO6 wake, listen 9 seconds for a frame before treating it as a Heltec reboot.
- Allowlist: `WAKE` (ACK, modem stays asleep), `STATUS` (ACK, then a normal status report), `MODEM_RESET` (ACK, then the same modem recovery as a forced watchdog check). Anything else is logged and not ACKed.
- The same seq is ACKed again and not run twice. An echoed `@TSIM ACK` is ignored.
- Frames that arrive while the T-SIM is already awake are handled the same way.
- No `@TSIM` frame: GPIO6 wake still means a Heltec reboot, as in 1.7.3–1.7.6.

## Unchanged
- No outgoing SMS. OTA, NVS config, and every WDCFG setting are unchanged.
- Nothing in this build has been sent to the T-SIM or the Heltec.
