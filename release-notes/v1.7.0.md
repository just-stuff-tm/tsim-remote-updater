## Access list (ACL) fixed
- The repeater prints `get acl` as plain lines with no `->` reply marker. Older T-SIM firmware treated that as "no reply from Heltec". 1.7.0 accepts this kind of output: it waits until the repeater has been quiet for 0.7 s, which also stops lists from being cut short.
- Dashboard: reads the MeshCore format correctly (`<permission hex> <public key>`). Already-saved replies show up without having to read them again.
- **Remove** in the ACL now sends `setperm <key> 0`. MeshCore 1.18 rejects `setperm` when no permission is given.

## Settings cache (optional, off by default)
- The T-SIM can refresh a copy of all repeater settings, regions and the ACL. It only does this during wakes that already happen (status text, scheduled report or a command), so caching never sends extra texts.
- In **Repeater settings › Settings cache**, turn it on and pick how often (6 h to 7 days). Fields filled from the cache are labeled "Cached by T-SIM". **Read** buttons still fetch live values.
- Only read-only commands are used, and the dashboard supplies the list. It is skipped while battery protection is on, and it stops if the repeater doesn't answer (for example, in power saving). If a part fails to upload, the T-SIM keeps it and sends it on the next wake.

## Telemetry with every report
- Every message from the T-SIM now carries a short snapshot: battery voltage and % (calibrated), solar voltage, signal, uptime, firmware, last GPS fix and chip temperature. The T-SIM card updates after every message, not only after status reports.
- Chip temperature comes from the ESP32's internal sensor. It runs warmer than the air around it.

Install: press **Update T-SIM firmware** in the dashboard (about 3 minutes).
