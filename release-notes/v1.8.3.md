# tsim-updater 1.8.3

## Quick local checks can run as seldom as every 2 days

Quick local checks (battery protection and the daylight uptime check) could only be set as far apart as 4 hours. They can now be set to 6 hours, 12 hours, 1 day or 2 days.

- The T-SIM still checks its modem once a day when check-ins are Off, so it cannot get stuck offline. That daily safety check is unchanged.
- A 2-day quick check is not reset when the daily safety check runs. The next quick check still happens at 2 days, not 2 days after every safety wake.
- Longer intervals save a little battery. Low-battery protection and the daylight uptime check only run on these checks, so they react more slowly.

## Battery check interval up to 2 days

The low-battery protection check interval can be set up to 2 days on T-SIM 1.8.3. Older T-SIM firmware still tops out at 4 hours (1.8.0–1.8.2) or 24 hours (before 1.8.0). The dashboard disables the longer quick-check options until this firmware is installed.

Install this firmware on the T-SIM (USB or T-SIM update). The repeater firmware does not need to change.
