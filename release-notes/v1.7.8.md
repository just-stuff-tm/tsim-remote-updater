## Faster replies

- A text wake (the modem ring) does not reset the modem. The T-SIM wakes it the same way a watchdog check does: DTR low, out of CSCLK sleep, then checks that AT answers and the modem is still registered. If AT does not answer after a few tries, or it is not registered within a short wait, it falls back to the full modem reset used before. Power-on and timer wakes are unchanged. Afterwards the modem is put back to sleep the same way as before.
- A console wake (`CMD`: repeater console and settings) posts the command replies, then skips the extra mesh snapshot, the extra AT diagnostics, and a follow-up `?sys=1` fetch when nothing is still pending. `STATUS` still takes the full snapshot and the diagnostics.
- The dashboard polls telemetry every 3 seconds for up to 3 minutes after a button that texts the T-SIM, and while a command is `sent`, then goes back to 30 seconds. It stops early once the replies are in. A firmware update still polls every 5 seconds. The page pauses while the tab is hidden, and only one request runs at a time.

Install from the dashboard with **Update T-SIM firmware**.
